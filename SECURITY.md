# Security Policy

## Supported Versions

We actively provide security updates for the following versions of EcoMind AI:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a potential security vulnerability in this project, please report it by emailing **pradhotkumar@gmail.com**. 

Once a report is received, we will:
1. Acknowledge the receipt of the report within 48 hours.
2. Provide an estimated timeframe for a fix.
3. Notify you once the vulnerability has been patched.

Thank you for helping keep EcoMind AI secure.
